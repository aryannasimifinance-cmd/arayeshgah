# بیوتی‌ست — BeautySet
*Beauty, beautifully booked.*

اپ رزرو سالن‌های زیبایی، اسپا و آرتیست‌های زیبایی **بانوان** در **تهران و کرج** — با امتیاز چندمعیاره و نظر فقط از مشتری واقعی.

## تب‌ها
| تب | چه دارد |
|---|---|
| کشف | شعار، نوبت بعدی، ۱۰ دسته‌ی خدمات، «ستاره‌های بیوتی‌ست» (آرتیست‌ها)، لوک‌بوک نمونه‌کارها، پیشنهادهای هفته، نزدیک شما، محبوب‌ترین‌ها |
| نقشه | نقشه‌ی واقعی با **۲۲ منطقه‌ی تهران و ۱۰ ناحیه‌ی کرج** (رنگ = تعداد سالن)، جستجوی زنده (سالن، آرتیست، خدمت، محله)، فیلتر دسته/امتیاز/باز است، کارت‌های پایین با لمس ناحیه |
| رزرو | سه قدم: چه خدمتی (دسته ← خدمت) · کجا (شهر + نقشه‌ی شماتیک نواحی) · کی (روز + بازه) و میان‌برها |
| نوبت‌ها | پیش‌رو / گذشته، لغو با برگشت بیعانه، رزرو دوباره، ثبت نظر |
| من | کیف پول، آرتیست‌های دنبال‌شده، سالن‌های نشان‌شده، اعلان‌ها |

ویزارد رزرو: خدمات (چندتایی، پشت هم) ← آرتیست (یا «فرقی نمی‌کنه») ← روز و ساعت آزاد ← تأیید و پرداخت بیعانه‌ی ٪۳۰.
نظر: پنج معیار (کیفیت کار، بهداشت، برخورد، وقت‌شناسی، ارزش قیمت) + برچسب + متن؛ امتیاز سالن و آرتیست هر دو به‌روز می‌شود.
آرتیست‌ها برند شخصی دارند: هندل، نشان ستاره/رو به رشد، دنبال‌کننده، کار امضا، نمونه‌کار، خدمات در منزل برای آزادکارها.

## دسته‌های خدمات
مو · رنگ و لایت · ناخن · ابرو و مژه · پوست و فیشیال · میکاپ · عروس · اپیلاسیون و لیزر · ماساژ و اسپا · آرایش دائم — ۵۲ خدمت با مدت و قیمت پایه در `src/lib/catalog.js`.

## اجرا
```bash
npm install
npm run dev
```
لینک‌های دمو: `#demo` (ورود با حساب نمونه)، `#demo=map`، `#demo=book`، `#demo=salon.s3`، `#demo=artist.a5`.
داده‌ها ساختگی و در مرورگر ذخیره می‌شوند (`src/lib/seed.js`؛ برای بازسازی `SEED_V` را بالا ببرید). نواحی روی نقشه از مرکز تقریبی هر منطقه ساخته شده‌اند و مرز رسمی شهرداری نیستند.

## ساختار
```
src/lib/catalog.js   دسته‌ها و خدمات، امکانات، معیارهای امتیاز
src/lib/geo.js       شهرها، مناطق و محله‌ها، برش نواحی روی نقشه
src/lib/seed.js      سالن‌ها، آرتیست‌ها، نظرها، ساعت‌های آزاد
src/lib/search.js    جستجو، فیلتر و مرتب‌سازی
src/components       Art (کاور و پرتره‌ی برداری)، Maps، cards، ui، Logo
src/screens          Gate · Shell · Discover · MapTab · Book · Results · Salon · Artist · Wizard · Visits · Me
```
